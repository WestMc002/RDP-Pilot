RDP Pilot
=================
Legt in .rdp-Dateien fest, auf welchem Monitor bzw. welchen Monitoren
eine Remotedesktop-Sitzung startet.

Erstellen
Erstellen.bat per Doppelklick ausführen. Benötigt .NET Framework 4.x (csc.exe).
Versionsnummer: Haupt.Neben.Jahr.MonatTag (z.B. 1.4.2026.1029).
Die Hauptversion steht in Erstellen.bat (MAJOR), die Nebenversion wird bei
jedem Erstellen automatisch um eins erhöht (höchste vorhandene Version + 1).
Bei Fehlern bleibt die alte EXE unverändert; Details stehen in Erstellen.log.
Nach dem Erstellen werden Vorschaubilder im Ordner Design\Vorschau erzeugt.
Auf Nachfrage (J, ohne Antwort nach 10 Sekunden Nein) erstellt sie außerdem die
Screenshots für GitHub im Ordner Screenshots – nur aus Beispieldaten
(erfundene Verbindungen und drei feste Beispielmonitore), hell und dunkel.
Direkt: "RDP Pilot.exe" --screenshots [Zielordner]

Backup
Nach jedem erfolgreichen Erstellen wird das gesamte Projekt (EXE, Quellcode,
Resources, Design, Anleitungen usw.) in einen eigenen Versionsordner kopiert:
Backup\RDP Pilot v<Version>
Ordnernamen im Projekt werden groß geschrieben (Backup, Design, Quellcode, Resources).
Erstellen.bat folgt der Standard-Vorlage (Globale Richtlinien).

Bedienung
Die EXE liest alle .rdp-Dateien aus ihrem eigenen Ordner ein.
Verbindung oben auswählen, Monitore in der Karte anklicken (mehrere möglich),
dann "Speichern & verbinden" oder "Speichern".
Weitere Dateien über "Andere Datei …" oder per Drag & Drop aufs Fenster. Sie werden
gemerkt und stehen beim nächsten Start wieder in der Liste; die zuletzt gewählte
Verbindung ist dann gleich ausgewählt.
Neue oder gelöschte .rdp-Dateien im Ordner erscheinen von selbst in der Liste;
F5 liest Ordner und Bildschirme von Hand neu ein.
"Identifizieren" blendet auf jedem Bildschirm kurz groß seine Nummer ein.
Ändern sich die Bildschirme, während das Programm läuft (z.B. Notebook an- oder
abgedockt), liest es sie neu ein. Ist eine Verbindung auf Bildschirme eingestellt,
die gerade nicht angeschlossen sind, warnt die Infozeile.
"Nur verbinden" verbindet auf den Monitoren, die gerade ausgewählt sind, ohne die
Verbindung zu ändern (dafür wird eine Kopie im Temp-Ordner gestartet). Ist nichts
geändert, wird die Verbindung direkt gestartet; fehlen dann gespeicherte
Bildschirme, fragt das Programm vorher nach.
Option "Sicherung erstellen" (standardmäßig aus): beim Speichern wird das
Original als <Datei>.rdp.bak gesichert, sofern noch keine Sicherung existiert.
"Original wiederherstellen" spielt sie zurück.

Design: Windows-11-Standard (Fluent) – Farben, Ecken und Schrift wie Windows 11,
helles/dunkles Design und Akzentfarbe werden aus Windows übernommen.

Ein Monitor:      use multimon:i:0, winposstr auf den Monitor, Auflösung optional
Mehrere Monitore: use multimon:i:1, selectedmonitors (erste ID = Hauptmonitor)

Hauptmonitor
Der Hauptmonitor ist der Monitor, auf dem in der Remote-Sitzung Taskleiste und
Startmenü erscheinen. Rechtsklick auf einen Monitor (oder Taste H) legt ihn fest.
Ohne Festlegung: lokaler Primärmonitor, falls ausgewählt, sonst der linke.
"Primär" kennzeichnet den Hauptbildschirm deines lokalen Windows.

Kommandozeile
"RDP Pilot.exe" Test.rdp 2,1            Monitore setzen (erster = Hauptmonitor)
"RDP Pilot.exe" Test.rdp 2,1 /connect   setzen und verbinden
Zusätzlich /backup: vorher Sicherung .rdp.bak anlegen

Quellcode: Quellcode\*.cs   Grafiken: Resources (Icon, App-Icon, GS-Logo)
Entwürfe: Design (Vorschaubilder)

Info-Fenster
Klick auf die Versionsnummer oben öffnet das Info-Fenster mit Version,
Eckdaten, Anleitung und dem Ordner der Verbindungen.

Update-Prüfung
Kurz nach jedem Start wird still auf GitHub geprüft, ob es eine neuere Version
gibt (github.com/WestMc002/RDP-Pilot, nur lesend, ohne Anmeldung). Gibt es
eine, erscheint oben im Fenster ein Hinweis mit "Jetzt aktualisieren",
"Release-Seite" und "Später". "Jetzt aktualisieren" lädt das ZIP, beendet das
Programm, ersetzt EXE und Liesmich (mit Sicherung) und startet neu; die
Verbindungen bleiben unverändert.
Im Info-Fenster zeigt die Zeile "Updates" den Stand und die letzte Prüfung,
"Jetzt prüfen" prüft von Hand, "Automatisch prüfen" schaltet die Prüfung ab.
Bei einem Fehler steht dort eine kurze Meldung, die genaue Ursache unter "Details".
Automatisch aktualisieren (Standard aus, nur zusammen mit "Automatisch prüfen"):
eine neue Version wird ohne Rückfrage installiert, sobald das Programm nicht
beschäftigt ist (keine ungespeicherte Monitorauswahl, kein Dialog offen; sonst
wird alle 5 Minuten erneut versucht). Danach startet das Programm von selbst neu.
Liegt das Programm unter "Programme", fragt Windows bei jedem Update nach
Administratorrechten.
Gespeichert wird das unter %LOCALAPPDATA%\RDP Pilot\Einstellungen.ini.
Ohne Internet bleibt alles wie gewohnt, es erscheint keine Fehlermeldung.
